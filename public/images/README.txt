PROFILE PORTRAIT IMAGE REPLACEMENT GUIDE
===========================================
To use your actual high-resolution headshot photograph:
1. Place your photograph file here named `profile-portrait.jpg` (or `.png`).
2. The portfolio is pre-configured to automatically load `/images/profile-portrait.jpg`.
3. If no custom image is found, it seamlessly falls back to `/images/profile-portrait.svg` (or the executive monogram badge) with zero layout disruption.
